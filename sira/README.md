# 🕌 السيرة النبوية

قسم مستقل عن خطة الكتب (مش داخل في حساب الوتيرة) — تبويب «سيرة» في هيدر التطبيق.

## ارفع دروس السيرة هنا

ملف HTML لكل درس، معمول بآلية عمل المحاضرات، ومسمّى برقم الدرس عشان يترتب صح:

```
01.html
02-المولد-والنشأة.html
```

- معرّف الصفحة (`data-lecture-id` على `<body>`): `moad_sira_01`، `moad_sira_02`، …
- السكريبتات بالمسار `../` (مش `../../` زي فولدرات الكتب).
- التطبيق بيكتشف أي ملف هنا لوحده ويعرضه في التبويب (HTML / PDF / صور / Markdown).
