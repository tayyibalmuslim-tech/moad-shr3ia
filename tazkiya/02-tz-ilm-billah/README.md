# ✨ العلم بالله

علم من علوم قسم «تزكية» في التطبيق.

## ارفع دروس «العلم بالله» هنا

- **دروس متفرقة:** ملف HTML لكل درس مباشرة في الفولدر ده، مسمّى برقم الدرس (`01.html` أو `01-عنوان-الدرس.html`).
  - معرّف الصفحة (`data-lecture-id`): `moad_tz-ilm-billah_01`، `moad_tz-ilm-billah_02`، …
  - السكريبتات بالمسار `../../`.
- **سلسلة محاضرات كاملة:** بتتضاف في `data.js` جوه `PLAN.sections.tazkiya.groups` (حقل `series` للعلم ده)، وفولدرها بيبقى جوه الفولدر ده: `tazkiya/02-tz-ilm-billah/01-<key>/`، وسكريبتاتها بالمسار `../../../`.
