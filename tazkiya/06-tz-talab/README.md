# 🎓 طلب العلم وآدابه

علم من علوم قسم «تزكية» في التطبيق.

## ارفع دروس «طلب العلم وآدابه» هنا

- **دروس متفرقة:** ملف HTML لكل درس مباشرة في الفولدر ده، مسمّى برقم الدرس (`01.html` أو `01-عنوان-الدرس.html`).
  - معرّف الصفحة (`data-lecture-id`): `moad_tz-talab_01`، `moad_tz-talab_02`، …
  - السكريبتات بالمسار `../../`.
- **سلسلة محاضرات كاملة:** بتتضاف في `data.js` جوه `PLAN.sections.tazkiya.groups` (حقل `series` للعلم ده)، وفولدرها بيبقى جوه الفولدر ده: `tazkiya/06-tz-talab/01-<key>/`، وسكريبتاتها بالمسار `../../../`.
