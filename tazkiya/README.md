# 🌿 تزكية

قسم مستقل عن خطة الكتب (مش داخل في حساب الوتيرة) — تبويب «تزكية» في هيدر التطبيق.

| الفولدر | العلم |
|---|---|
| `01-tz-tazkiya/` | 🌱 التزكية |
| `02-tz-ilm-billah/` | ✨ العلم بالله |

كتب المنهج (التزكية، وسير ومناقب، والأخلاق، وطلب العلم) مكتوبة في `data.js` كـ `books` لكل علم، وبتظهر في صفحته كقايمة ورد بالترتيب — مش داخلة في حساب الوتيرة.
