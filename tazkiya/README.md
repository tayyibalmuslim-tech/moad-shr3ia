# 🌿 تزكية

قسم مستقل عن خطة الكتب (مش داخل في حساب الوتيرة) — تبويب «تزكية» في هيدر التطبيق.

## ارفع دروس التزكية هنا

ملف HTML لكل درس، معمول بآلية عمل المحاضرات، ومسمّى برقم الدرس عشان يترتب صح:

```
01.html
02-الإخلاص.html
```

- معرّف الصفحة (`data-lecture-id` على `<body>`): `moad_tazkiya_01`، `moad_tazkiya_02`، …
- السكريبتات بالمسار `../` (مش `../../` زي فولدرات الكتب).
- التطبيق بيكتشف أي ملف هنا لوحده ويعرضه في التبويب (HTML / PDF / صور / Markdown).
